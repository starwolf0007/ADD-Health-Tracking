# Unlock Sprint — Reflect Surface Brief

**Date:** 2026-07-27  
**Status:** Active (direction locked; implementation staged)  
**Authority:** Unlock Sprint (`docs/UNLOCK-SPRINT-MEMO.md`, ADR-008) + owner product direction

This brief applies **only to Reflect**. Agents must not expand Reflect into journaling, analytics, or a second dashboard.

---

## Mission (one question)

**Reflect is not journaling.**  
**Reflect is not analytics.**  
**Reflect is not another dashboard.**

Reflect answers **one** question:

> **What happened today, and what can I learn from it?**

Everything else can come later.

---

## Philosophy

Fits NeuroFlow better than charts and statistics:

- **No scores**
- **No grades**
- **No “you failed.”**

Just:

- what happened,
- what changed,
- optional observations.

Calm chronological narrative of the day — evidence the user already generated by living in the app — not a performance report.

Mood check-ins remain an **input** to that story (and still drive Quick Wins on Today). They are not the whole product of Reflect.

---

## MVP definition

### Inputs (reuse existing stores; do not invent parallel systems)

| Input | Source | Notes |
|-------|--------|--------|
| Mood check-ins | `MoodLog` / Reflect chips | Labels only (Rough → Great); on-device only (§2.8) |
| Completed tasks | Task repository / timeline | Completions for the viewed day |
| Habits | Habit check-ins | Done / not done for the day |
| Workout summary | Hevy import if present | Optional; omit section if none |
| Sleep summary | Health Connect when wired | Optional; omit until available |
| Notes created today | `Note` / notes provider | Capture that landed today |

### Output

**One calm chronological timeline** for the day:

- Ordered by time (or logical day order where timestamps are coarse)
- Plain language items (“Completed …”, “Checked in Rough”, “Note: …”)
- Empty states that invite a single next action, not guilt
- Optional short observation only if it is deterministic and non-judgmental (e.g. “Quick Wins mode was active after a low check-in”) — never moralizing

### Explicit non-goals for MVP

- Journaling prompts / free-form diary as the primary surface
- Charts, streaks-as-scores, grade-like summaries
- Leaderboards, comparisons, “productivity score”
- Lexi auto-essays or AI summaries as a hard dependency
- Cross-day analytics dashboards

---

## Tiering (for implementers)

### Tier 1 — Daily-driver Reflect

1. Day-scoped **chronological timeline** composed from existing local data (mood, completed tasks, habits, notes-today; workouts if already imported).
2. Mood check-in remains available on the same screen (or one tap away) because it is both an input and a Quick Wins signal.
3. Clear empty / loading / error states; calm theme tokens; no numeric self-judgment UI.
4. Local-only; no cloud mood/reflect sync.

### Tier 2 — Soon (report; change only if costly to delay)

- Sleep / Health Connect rows when ingestion exists
- Soft grouping (morning / afternoon / evening) without becoming a dashboard
- Link-out to the originating surface (task, note) without coupling Executive to Reflect UI

### Tier 3 — Defer

- Rich journaling
- AI narrative summaries as default
- Charts and trend analytics
- Export / share cards
- Multi-day comparison views

## Architectural constraints

- Executive stays pure Dart; Reflect is presentation + repository reads.
- Mood never syncs (§2.8).
- Prefer composing streams from existing repositories over new “Reflect tables.”
- Temporary incomplete sections (e.g. no sleep yet) must be omitted or labeled honestly — not fake charts.

## Required stop

Implement or extend Reflect only under this brief. After a meaningful Tier 1 increment, **stop** and wait for owner confirmation before Settings / Lexi surfaces.
